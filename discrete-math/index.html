五种基本联结词（命题逻辑）

设 p、q 为命题变元。五个联结词的真值定义如下，例句中的 p、q 都是日常命题。

¬p
否定Negation
p 真则 ¬p 假；p 假则 ¬p 真。
p：今晚有作业。¬p：今晚没有作业。
p∧q
合取Conjunction
当且仅当 p、q 都为真时为真。
p：周末加班，q：周末值班。两件事都发生才算。
p∨q
析取Disjunction
当且仅当 p、q 都为假时为假（可兼或）。
p：吃面，q：吃饭。可以只吃一样，也可以都吃。
p→q
蕴含Implication
仅当 p 真而 q 假时为假；p 假时恒真（善意约定）。
p：下雨，q：带伞。没下雨时无论带没带伞都不算错。
p↔q
等价Biconditional
p、q 真值相同时为真，即"当且仅当"。
p：两数相等，q：两数差的绝对值为 0。
优先级与结合性
优先级（高 → 低）结合性示例
括号  >  ¬  >  ∧  >  ∨  >  →  >  ↔ → 为右结合 p→q→r ≡ p→(q→r)

例如 ¬p∧q→r 应读作 (¬p∧q)→r——这也是手工做题时最容易看错的一步。

常用等值式（第二章必背）

每一条都可以在「命题逻辑」一栏现场验证——点公式自动填入核验框。

¬(p∧q) ≡ ¬p∨¬q　　¬(p∨q) ≡ ¬p∧¬q
德摩根律。
p→q ≡ ¬p∨q
蕴含展开。
p→q ≡ ¬q→¬p
逆否律（注意与逆命题 q→p 区分）。
¬¬p ≡ p
双重否定律。
p∧(q∨r) ≡ (p∧q)∨(p∧r)
分配律。注意 ≠ (p∧q)∨r，后者漏掉了 r 单独成真的情形。
p∨(p∧q) ≡ p
吸收律。
(p∧(p→q))→q 是重言式
假言推理（modus ponens）。
p∨¬p 是重言式，p∧¬p 是矛盾式
排中律与矛盾律。
集合运算常用恒等式

与命题逻辑的等值式一一对应（把 ∧ 读作 ∩、∨ 读作 ∪、¬ 读作补），可在「集合」一栏验证。

A−(B∪C) = (A−B)∩(A−C)
差集德摩根律。AI 常把右式写成 (A−B)∪(A−C) 或把 ∪ 写成 ∩。
A∩(B∪C) = (A∩B)∪(A∩C)
交对并的分配律。AI 常写成 (A∩B)∪C，漏掉 C 单独剩下的元素。
|P(A)| = 2^|A|
幂集基数：n 元集的幂集有 2ⁿ 个元素。AI 常算成 n² 或 2n。
A⊆B ⇔ A∪B=B ⇔ A∩B=A
包含的三种等价刻画，也是子集判定的算法依据。
关系的性质

设 R ⊆ A×A。四条基本性质 + 两个复合概念，可在「关系」一栏验证，反例给序偶。

性质定义典型反例
自反每个 x∈A 都有 (x,x)∈R基集 {1,2,3}，R 里缺 (3,3)
对称(x,y)∈R ⇒ (y,x)∈R(1,2)∈R 但 (2,1)∉R
传递(x,y),(y,z)∈R ⇒ (x,z)∈R(a,b),(b,c)∈R 但 (a,c)∉R（指导书示例②）
反对称(x,y),(y,x)∈R ⇒ x=y(1,2) 与 (2,1) 同时在 R 里
等价关系自反 + 对称 + 传递三条里缺任何一条都不是
偏序关系自反 + 反对称 + 传递同上

空关系在非空基集上是对称、传递、反对称的（前提为假蕴含式恒真），但不自反——这是常见边界情形。

图论：欧拉回路与欧拉路径

一笔画问题。判定条件是必要充分的，且必须先检查连通性（不计孤立顶点）。

存在欧拉回路 ⇔ 连通 且 所有顶点度数为偶
从任一点出发回到原点，每条边恰好走一次。
存在欧拉路径 ⇔ 连通 且 奇度顶点恰为 0 或 2 个
恰 2 个奇度顶点时，路径必须从其中一个奇度点出发、在另一个结束。

经典易错：给正方形加一条对角线后，有两个 3 度顶点——没有欧拉回路，但仍有欧拉路径。AI 常把两个判定混为一谈。

常见错误类型

AI 与初学者最常犯的几类错——案例回归里的"杀手案例"就是按它们设计的。

标签错误内容典型例子
IMPL_CONV把蕴含当成对称关系，逆命题当等价p→q 与 q→p（p 假 q 真时一真一假）
DIST_DIR分配律只分配了一项p∧(q∨r) 与 (p∧q)∨r；A∩(B∪C) 与 (A∩B)∪C
SET_LAW德摩根律方向用反¬(p∧q) 写成 ¬p∧¬q；A−(B∩C) 写成 (A−B)∩(A−C)
REL_PROP关系的性质凭"看起来"判断(a,b),(b,c) 就说传递；空关系说成自反
GRAPH_EULER欧拉回路与欧拉路径混为一谈，或漏查连通性两个奇度顶点的图说成有欧拉回路
PARSE_FAIL输入残缺，系统拒答不猜答案p∧（缺右操作数）、{1,2（缺右括号）

这个项目能用在什么地方
  • 核验 AI 的答案（核心目标）：AI 答题很方便，但结论对不对它自己不负责。把题目和 AI 原话录入进来，拆成原子结论逐条核验，错了拿到可复现的反例。
  • 课程知识点诊断系统：按指导书设想，每章变成系统的一个核验器；把学生易错点做成案例库，哪条结论错、错在哪个知识点，一目了然。
  • 自动反例生成器：核验器发现错误结论时顺手产出反例（反例赋值 / 反例序偶 / 奇度顶点），本身就是做题时最想要的东西。
  • 平时做题自查：化简、演算、判性质的每一步随手验一下，比翻书快。
  • 再往前一步：把权限规则、业务规则写成命题公式，用等价 / 蕴含检查有没有冲突或废话——同一套方法可以直接搬过去。
